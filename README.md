# Blichat

Blichat — современный Android-мессенджер в минималистичном чёрно-бордовом стиле.

## Что уже есть
- экран списка чатов;
- экран переписки;
- отправка сообщений в локальном тестовом режиме;
- кнопки голосового и видеозвонка;
- экран профиля;
- экран звонков;
- Material 3 + Jetpack Compose;
- готовая структура Android-проекта.

## Важно
Это рабочий UI-прототип. Для настоящих аккаунтов, сообщений между устройствами, push-уведомлений и звонков нужно подключить backend (например, Supabase) и WebRTC/телефонную инфраструктуру.

## Сборка APK
Открой проект в Android Studio, дождись Gradle Sync и выбери:
Build → Build APK(s)

Готовый debug APK будет находиться в:
app/build/outputs/apk/debug/app-debug.apk
